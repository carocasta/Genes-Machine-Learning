# RNA-seq Data Processing Pipeline

## Overview

This repository contains a Bash script for processing RNA-seq data to generate gene-level expression counts. The pipeline includes quality control, read trimming, alignment to the human reference genome, and gene quantification.

## Bioinformatics Workflow

The pipeline consists of the following steps:

1. **Data retrieval:** Download raw sequencing files from Amazon S3.
2. **Quality control:** Evaluate raw sequencing reads using FastQC.
3. **Read trimming:** Filter and trim sequencing reads using Cutadapt.
4. **Read alignment:** Align paired-end reads to the human reference genome using STAR.
5. **Gene quantification:** Generate gene-level counts using featureCounts.
6. **Data storage:** Upload the resulting count matrix to Amazon S3.

## Tools

- FastQC
- Cutadapt
- STAR
- featureCounts (Subread package)
- AWS CLI

## Input

Paired-end RNA-seq FASTQ files (`.fq.gz`).

## Output

A gene-level raw count matrix generated by featureCounts.

## Script

`procesamiento_english.sh`

The script contains the complete processing workflow, including data retrieval, quality control, trimming, alignment, quantification, and file management.

## Research Context

This pipeline was used as part of a doctoral research project focused on developing interpretable machine learning models to predict response to anti-PD-1/PD-L1 immune checkpoint inhibitors using transcriptomic data from patients with solid tumors.

## Notes

The script contains environment-specific file paths and computational settings that must be adapted before execution on other systems.
